# Rozalina Handmade

Website za [@rozalina_handmade](https://www.instagram.com/rozalina_handmade/): ručno rađeni pokloni iz Zenice.

Čisti HTML, CSS i JavaScript, bez build koraka.

- `index.html`: cijela stranica (hero, kolekcije, ponuda, po želji, o meni, kontakt)
- `styles.css`: dizajn i animacije
- `script.js`: slider, filteri, modal proizvoda, omiljeni, latice
- `images/`: fotografije proizvoda (WebP) i logo

## Cloudflare Pages

- Framework preset: None
- Build command: (prazno)
- Build output directory: `/`

Svaki push na `main` automatski se objavljuje.
